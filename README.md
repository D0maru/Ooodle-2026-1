# Ooodle-2026-1
Intento de replica del juego en: https://mathszone.co.uk/resources/grid/ooodle/ a partir de java y javaFX

Requisitios previos:
Java 21 (JDK o JRE) 
JavaFX 21 SDK

Instrucciones de ejecucion
Ubicar el archivo .jar en la carpeta raiz del proyecto y ejecutarlo, de otro modo
en la carpeta src que contiene la arquitectura MVC, ubicar la carpeta Vista y ejecutar el App.java en un IDE donde el proyecto este abierto como proyecto Java maven
